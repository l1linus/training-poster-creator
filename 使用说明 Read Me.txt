🎨 培训海报生成器 · 使用说明

培训海报生成器：把培训主题、讲师、时间、亮点等信息填入表单，在本地渲染成一张竖版科技风海报 PNG；支持模板与配色切换、上传讲师照片和二维码，并按培训日期自动换算欧中、美西、美东时间及夏令时/冬令时。工具包通过 GitHub 仓库分发。

本工具提供两种使用方式，按场景选择即可：

- Skill 版（推荐，SKILL.md + 整个文件夹）：由 Agent 读取 skill 后一句话启动本地工作台，支持批量出图、MCP 接入。适合：WorkBuddy 等本地 Agent 平台、批量/无人值守出图、多平台复用。前提：平台能读取 SKILL.md（或支持 MCP），且必须复制整个文件夹（只复制 SKILL.md 没用）。
- 网页版（HTML）：双击「培训海报生成器 Training Poster Generator.html」，自己填表、导出 PNG。不需要安装软件、不需要联网、数据不上传。适合：偶尔做一张海报、只需分发一个文件给他人、云端 Agent 无法访问本机时兜底。

一、Skill 版：常见平台使用指引

从 GitHub 仓库获取工具包并解压，确保 SKILL.md 位于文件夹第一层。

环境要求：Node.js ≥ 20，但无需手动安装——首次发出「开始生成培训海报」等启动命令后，脚本会自动联网下载便携版（约 35 MB）到 .runtime/，不写入系统。想省去下载步骤可自行安装 Node 20+；完全离线的环境请提前装好 Node，或把 .runtime/ 一并带上。

- WorkBuddy：把整个文件夹放到 C:\Users\<用户名>\.workbuddy\skills\（用户级）或 <项目>\.workbuddy\skills\（项目级），重开会话后说「开始生成培训海报」。Agent 会启动工作台并给出 http://127.0.0.1:4173/。
- Claude Code / DSH 等支持 SKILL.md 的运行时：整个文件夹放进对应 skills 目录，按平台方式触发（一般直接说「开始生成培训海报」）。
- 能执行命令的其他 Agent：让它跑 scripts/bootstrap.ps1（Windows）或 bootstrap.sh（macOS/Linux），或 node scripts/open-ui.mjs --no-open，拿到 URL 即可。
- Claude Desktop / Cursor 等 MCP 客户端：把 scripts/mcp.mjs 配成 stdio server，用 open_editor 打开工作台、render_poster 批量出图。

触发后，在打开的页面里填信息、预览、导出即可（同网页版第 2、3 步）。
想让 Agent 直接出图：说「不用界面，按以下信息生成海报 PNG：……」；首次需执行 npm install，并确保装有 Edge / Chrome。

二、网页版：3 步使用

1. 双击「培训海报生成器 Training Poster Generator.html」
   浏览器会打开（Edge / Chrome 都可以）。
   双击没反应：右键 → 打开方式 → 选 Edge 或 Chrome。

2. 左边填信息
   只填「培训主题」也能出图。
   模板、配色、讲师照片、二维码都可以在界面里改。
   模板选「上传素材获取颜色风格」时，会在本机自动取色，不需要 AI、不上传图片。
   时间按培训日期自动换算夏令时/冬令时。

3. 点「生成预览」，再点「导出 PNG」
   图片会保存到浏览器的“下载”文件夹。

不需要安装任何软件，不需要联网，不上传任何数据。

三、要点与常见问题

- 分发给他人：只供浏览器出图 → 只发「培训海报生成器 Training Poster Generator.html」；要让 Agent 使用 skill → 分享整个解压后的文件夹（或给出 GitHub 仓库链接）。
- 下载 Node 失败：检查网络，或自装 Node 20+ 后重试；离线环境提前带 .runtime/。
- 云端 Agent 访问不到 127.0.0.1：用本地/桌面版，或改用网页版。
- 说「开始生成培训海报」没反应：确认 SKILL.md 在文件夹第一层、文件夹在 skills 目录，重开会话。
- 页面空白：换 Edge / Chrome 打开，不要用 IE。
- 照片、二维码没显示：重新选一次文件。
- 导出没反应：检查浏览器是否拦截了下载。
- 提示缺少 playwright-core：在技能目录执行 npm install。
